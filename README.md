This is currently just a minimal test of accessing a USB MIDI device in the browser via JS and a JS library that can render sheet music. In the future I plan to use this to create custom Piano lessons for my own practice. Coding it as a simple browser web app is an easy way to make it cross-platform and run it on a tablet or phone connected to an ePiano. I vibe coded the example code because I was mainly interested in first testing whether MIDI in a browser works on my devices.
